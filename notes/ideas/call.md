# 内核调用

内核调用分两类：System Call（用户进程 ↔ 内核）与 Remote Call（hart ↔ hart，内核态内部）。

## System Call

由进程调用内核，用 Ecall 实现，有返回值。分同步与异步两类。

同步调用处理完成即返回结果，是最常用的形态。异步调用期间内核不等待——接受请求后立即调度其他任务；调用者线程转入等待态（Waiting），排队中的请求由**内核请求**（Kernel Request）表示：描述等待对象与完成动作，是异步调用的记账单元。

请求完成后线程被直接唤醒回就绪态（Ready），结果已写入其执行现场，恢复运行即拿到结果——无需重新触发系统调用，无中间状态、无重入重试。

## Remote Call

远程调用：一个 hart 请求另一个同类型 hart 在其核上执行一个内核态动作。用 IPI 作门铃唤醒目标核，请求参数放共享内存，由目标核取用；是否需要返回值、载荷多大，由第一个消费者决定。目前没有实现也没有应用。

可预见的应用：TLB shootdown、跨核负载均衡通知、内核调试通道。
